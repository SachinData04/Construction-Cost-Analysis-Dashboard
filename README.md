Project Overview

This project presents an interactive Construction Cost Analysis Dashboard developed using Power BI and Excel to analyze construction cost, quantity trends, and work-type distribution using real-world datasets.

The dashboard provides insights into project cost allocation, quantity by category, and construction work distribution through interactive KPI cards, charts, and visuals.

Key Features
Total Construction Cost KPI
Quantity Analysis by Category
Construction Cost Breakdown (Pie Chart)
Work Type Cost Analysis (Bar Chart)
Interactive Data Visualization using Power BI
Tools Used
Power BI
Microsoft Excel
Power Query
Business Objective

To analyze construction-related cost and quantity data for better project visibility, reporting, and cost analysis.
